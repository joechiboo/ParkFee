# ParkFee

社區機車車位登記、抽籤與清潔費管理工具。

把樂菲莊園《社區地下室停車場管理辦法》的機車條文，變成一套**可重現、可稽核**的年度作業工具：
**登記 → 抽籤 → 車位分配 → 繳費 → e-Tag 名單**，跑完一輪就能交付管委會執行。

## 背景

- 區權會已通過機車清潔費 100 元／月（抽中後一次繳一年 **1,200 元**），管委會需據此執行。
- 管理辦法已採「抽籤＋固定車位」制。本工具負責把規則自動化、留下可監察的紀錄，解決「實行細則沒定就不敢上路」的卡點。

## MVP 範圍（最小閉環）

1. **登記名冊**：戶號、車號、車種（一般／250CC↑重機）、第幾輛、是否身障、是否志願小機車位。一戶限登記一次（第一輛）。
2. **分階段配位**：階段 1 保障每戶一位（志願小位免抽依序選、其餘抽車位資格選號），階段 2 用剩餘車位開放多位、超額公開抽籤＋候補。**顯示亂數種子供權責委員監察、結果可重現。**
3. **車位分配＋繳費**：分配車位編號、計算應繳（1,200／3,600）、記錄繳費與簽約期限、放棄則候補遞補。
4. **e-Tag 白名單匯出**：輸出「車號 → 可通行」CSV，給智慧停車系統砍掉未登記車輛。
5. **車牌辨識＋巡邏稽核（純前端）**：登記時掃描帶入車號；巡邏拍照辨識 → 比對名冊 → 標記「停錯位／佔用／未登記」→ 產生勸導單。辨識為輔、人工確認為準，照片在裝置端處理、不上傳。

不在 MVP（Phase 2）：退租退費試算、合約／申請書套印、汽車與自行車、線上登記表單、年度歷史、自動車牌偵測模型。

## 不收個資

v1 只處理 **戶號＋車號**，不存身分證號 — 簽約與身分查驗留在管理中心線下進行，降低資料保護負擔。車牌辨識的照片全程在裝置端處理、不上傳、用後即棄。

## 技術

- Vue 3 + Vite + Tailwind，部署 GitHub Pages
- 無後端：名冊以 CSV 匯入、結果以 CSV 匯出（名冊仍維護在管委會既有試算表）
- 抽籤使用固定種子的亂數，結果可重現、可稽核
- 車牌辨識純前端：Tesseract.js（v1，框選＋校正後辨識），升級可換 onnxruntime-web 自動偵測

## 規則來源

樂菲莊園社區地下室停車場管理辦法（115/01/28 訂定、115/03/21 修訂）。
機車位總數 655：一般大 320、一般小 327、無障礙 8。
