## 對應系統欄位（給登錄人員 / 開發者）

紙本各欄對應線上登記與 CSV schema（見 [12-機制合規與建置規劃](12-機制合規與建置規劃.md) §4.6）：

| 紙本欄位 | 系統欄位 |
|---|---|
| 戶號 | `戶號` |
| 聯絡電話 | `聯絡電話` |
| 收件時間 | `登記時間` |
| 第 N 輛·車號 | `車號`（登錄時正規化：大寫、補連字號） |
| 第 N 輛·車種（一般/重機） | `車種` |
| 第 N 輛·需無障礙位（是/否） | `身障`（Y/N） |
| 第 N 輛·志願小位（是/否） | `志願小位`（Y/N） |
| 順序（第 1/2/3 輛） | `第幾輛` |
| 車位志願序（全戶共用一份） | `車位志願`（陣列；**戶層級、與車輛數無關**，登錄前各別正規化為車位編號） |
| 志願落選保底（勾選與否） | `志願落選保底`（Y/N，預設 N） |

> 登錄原則：與線上表單同一套去重規則——同戶號以最新一次為準；車號登錄前先正規化。

## 注意事項

1. **第 2、3 輛不提供無障礙選項**：無障礙車位以「人」為單位優先配給，故僅第 1 輛列該欄。
2. **紙本與線上等效**：同樣進入抽籤池，無優先或劣後之別。
3. **重機與志願小位**：重機佔雙位，一般不適用「志願小位」；如住戶於重機列勾選志願小位，受理人員應提醒確認。
4. **行照查驗**：紙本登記的優勢是現場即可核對行照，請受理人員務必勾選確認。
5. **車位志願序（戶層級）**：全戶共用一份，**與登記車輛數無關**。抽出順序號後，依序分發「志願中仍剩的最高志願」（大學分發式）；多台車輪到時各自從同一份清單取最高可得者。志願填越多越能避免落空。僅一般大位／重機需填；志願小位、無障礙位免填。
6. **填無效或空白車位志願**：視同未表達偏好——若有勾「志願落選保底」由物業就近代配，否則進候補。受理人員登錄時應剔除非該車種可停的車位編號（如一般車填到無障礙位）。
