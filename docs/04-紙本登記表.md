# 樂菲莊園 車位紙本登記表

> 供不便使用線上登記者（如長者）填寫；管理中心服務人員協助登錄至系統。
> 欄位與線上登記系統一致，匯入後同樣進入抽籤配位，**無優先或劣後之別**。
> **本表只做登記，不收任何費用。** 抽中車位後再到管理中心簽約繳費。
> **須隨表附「B1 車位平面圖」**（含車位編號）供住戶填車位志願序；長者可由服務人員對照協助填寫。
> 可直接列印之版本：[forms/登記表-紙本.html](forms/登記表-紙本.html)（瀏覽器開啟即印）。
> **社區工作人員共用本表**（2026-08-26 定）：勾「身分別＝社區工作人員」，並簽署表末之工作人員承諾事項；
> 配位排在全體住戶之後，住戶未配完則暫緩（辦法伍二（十二））。

## 對應系統欄位（給登錄人員 / 開發者）

紙本各欄對應線上登記與 CSV schema（見 [12-機制合規與建置規劃](12-機制合規與建置規劃.md) §4.6）：

| 紙本欄位 | 系統欄位 |
|---|---|
| 身分別（住戶／社區工作人員） | `工作人員`（Y/N）——勾工作人員者為 Y |
| 戶號（住戶）／服務單位·職務（工作人員） | `戶號`；工作人員無戶號，登錄以合成鍵 `員工-<編號>` 代之 |
| 聯絡電話 | `聯絡電話` |
| 社會住宅承租戶（勾選） | `社宅`（Y/N，**戶層級**） |
| 收件時間 | `登記時間` |
| 第 N 輛·車號 | `車號`（登錄時正規化：大寫、補連字號） |
| 第 N 輛·車種（一般/重機） | `車種` |
| 第 N 輛·需無障礙位（是/否） | `身障`（Y/N） |
| 第 N 輛·志願小位（是/否） | `志願小位`（Y/N） |
| 順序（第 1/2/3 輛） | `第幾輛` |
| 自行車第 N 台 | `車種`＝自行車；`車號` 由系統產合成鍵 `自行車-<戶號>-<序>`（**登錄人員免填**） |
| 車位志願序（全戶共用一份） | `車位志願`（陣列；**戶層級、與車輛數無關**，登錄前各別正規化為車位編號） |
| 電腦選號（勾選與否） | `志願落選保底`（Y/N，預設 N；欄位名沿用舊稱、後端相容） |

> 登錄原則：與線上表單同一套去重規則——同戶號以最新一次為準；車號登錄前先正規化。
> 登錄完成後可跑 `node scripts/check-roster.mjs` 做資料健檢（社宅超額、車號重複、志願錯配等）。

## 注意事項

1. **第 2、3 輛不提供無障礙選項**：無障礙車位以「人」為單位優先配給，故僅第 1 輛列該欄。
2. **紙本與線上等效**：同樣進入抽籤池，無優先或劣後之別。
3. **重機**（2026-08-16 小組決議否決專區、2026-08-24 補定無障礙單格）：
   **不設專區**，穿插一般車位取**相鄰兩格**（不限大、小）；亦得承租**無障礙位（單格）**。
   志願填想要的起始編號即可，系統自動帶鄰格；湊不到相鄰對且無剩餘無障礙位則落選候補。
   重機不適用「志願小位」；如住戶於重機列勾選志願小位，受理人員應提醒確認。
4. **社會住宅戶**（Q7）：勾選後**限承租公益設施車位**（機車 1–7、92–104；自行車 114–118），
   免填車位志願序。惟**無障礙位不分社宅身分**——社宅之行動不便者仍可循無障礙優先配給。
5. **車位志願序（戶層級）**：全戶共用一份，**與登記車輛數無關**。抽出順序號後，依序分發
   「志願中仍剩的最高志願」（大學分發式）；多台車輪到時各自從同一份清單取最高可得者。
   志願填越多越能避免落空。
6. **填無效或空白車位志願**：視同未表達偏好——若有勾「電腦選號」由系統自動配本棟靠電梯
   剩位，否則保留待事後自選／候補。受理人員登錄時應剔除非該車種可停的車位編號
   （如一般車填到無障礙位、一般戶填到公益位）。
7. **自行車**：不排志願、隨機配位、不收費；抽中後簽承諾書並領識別貼紙。純自行車戶因無
   車牌不能線上登入，**電話務必留存**，日後異動一律由管理中心協助辦理。
8. **社區工作人員**（2026-08-26 定：共用本表）：勾「身分別＝社區工作人員」並簽署表末承諾事項。
   與住戶**同梯登記、同樣可填志願**，但**配位排在所有住戶之後**——辦法伍二（十二）限制的是配位
   時點（「停車資格程序完結後如有剩餘車位」），非登記時點。**只要還有住戶未配得車位（第 1 輛落選
   且全戶無位），工作人員一律暫緩、不先占位**。免收費、不得申請公益位與無障礙位、住戶申請時
   無條件讓出。引擎已實作（`distribute.js` 最後一輪、`REASON.STAFF_PENDING`）。
