# 樂菲莊園 車位紙本登記表

> 供不便使用線上登記者（如長者）填寫；管理中心服務人員協助登錄至系統。
> 欄位與線上登記系統一致，匯入後同樣進入抽籤配位，**無優先或劣後之別**。
> **本表只做登記，不收任何費用。** 抽中車位後再到管理中心簽約繳費。
> **須隨表附「B1 車位平面圖」**（含車位編號）供住戶填車位志願序；長者可由服務人員對照協助填寫。
> **社區工作人員共用本表**（2026-08-26 定）：勾「身分別＝社區工作人員」；
> 配位排在全體住戶之後，住戶未配完則暫緩（辦法伍二（十二））。

## 版面結構（2026-10-15 一頁版；2026-10-30 志願小位改「限機車 1、登記時直接劃位」）

1. **申請人資料**：身分別（住戶＝戶號／工作人員＝單位職務）、申請人、電話、社宅勾選。
   不另設「登記日期」，以管理中心欄的收件時間為準（10/16 為塞進一頁而去重）。
2. **一、登記車輛**（單一表格）：機車 1、機車 2、自行車各一列。
   欄位＝車號／自行車特徵、車種（一般／重機；自行車列固定）、需無障礙位（僅機車第 1 輛）、
   **志願小位（僅機車第 1 輛）：「□是→小位號＿＿」**——勾選即免抽籤，住戶對照平面圖**當場填入**想要的小位編號，
   櫃台核對該號未被登記後受理（依登記順序，先到先選；2026-10-29 臨時管委會：表格 A 不另立、限第一部，見 [34](34-會議紀錄-2026-10-29-臨時管委會.md)）。
   **超過 2 輛機車或 1 台自行車者另填一張**（2026-10-15 經理要求濃縮成一頁後定）。
   **版面驗收標準**：Word「標準邊界」（上下 2.54cm、左右 3.18cm）印出仍為一頁。Word 排得比瀏覽器鬆，
   用 Edge 依此邊界轉 PDF 時版心應用到 80% 以下（10/16 放大字級後為 85%）。檔內另嵌 Word 窄邊界設定。
3. **二、車位志願序**：①–⑩ 空格（可續填背面）＋「電腦選號」勾選。
4. **三、填表人確認**：同意辦法、知悉繳費期限、工作人員知悉事項；簽名。
5. **管理中心填寫**：收件時間、收件編號、**志願小位核對（號碼未被登記、已登入小位名冊）＋核對人員**、受理人員、已登錄系統、登錄人員。

## 對應系統欄位（給登錄人員 / 開發者）

紙本各欄對應線上登記與 CSV schema（見 [12-機制合規與建置規劃](12-機制合規與建置規劃.md) §4.6）：

| 紙本欄位 | 系統欄位 |
|---|---|
| 身分別（住戶／社區工作人員） | `工作人員`（Y/N）——勾工作人員者為 Y |
| 戶號（住戶）／服務單位·職務（工作人員） | `戶號`；工作人員無戶號，登錄以合成鍵 `員工-<編號>` 代之 |
| 聯絡電話 | `聯絡電話` |
| 社會住宅承租戶（勾選） | `社宅`（Y/N，**戶層級**） |
| 收件時間（紙本不另設登記日期） | `登記時間` |
| 第 N 輛·車號 | `車號`（登錄時正規化：大寫、補連字號） |
| 第 N 輛·車種（一般/重機） | `車種` |
| 第 N 輛·需無障礙位（是/否） | `身障`（Y/N） |
| 機車 1·志願小位（勾選） | `志願小位`（Y/N）；**限第 1 輛**，第 2 輛起無此欄 |
| 機車 1·小位號（住戶當場填的編號） | 不進名冊欄位；櫃台核對後於**指派維護頁**（`SeatAdminView`）把該車指派到該小位（`locked_seat`＋`vehicle`），`distribute` 不再配這台車 |
| 順序（第 1/2 輛；第 3 輛起填第二張） | `第幾輛`（第二張接續編號 3、4…） |
| 自行車第 N 台 | `車種`＝自行車；`車號` 由系統產合成鍵 `自行車-<戶號>-<序>`（**登錄人員免填**） |
| 車位志願序（全戶共用一份） | `車位志願`（陣列；**戶層級、與車輛數無關**，登錄前各別正規化為車位編號） |
| 電腦選號（勾選與否） | `志願落選保底`（Y/N，預設 N；欄位名沿用舊稱、後端相容） |

> 登錄原則：與線上表單同一套去重規則——同戶號以最新一次為準；車號登錄前先正規化。
> 登錄完成後可跑 `node scripts/check-roster.mjs` 做資料健檢（社宅超額、車號重複、志願錯配等）。

## 注意事項

1. **第 2 輛起不提供無障礙選項**：無障礙車位以「人」為單位優先配給，故僅第 1 輛列該欄。
   同戶填第二張時，第二張的「第 1 輛」列視同第 3 輛，**無障礙欄不再勾**；受理人員登錄時留意。
2. **紙本與線上等效**：同樣進入抽籤池，無優先或劣後之別。
3. **重機**（2026-08-16 小組決議否決專區、2026-08-24 補定無障礙單格）：
   **不設專區**，穿插一般車位取**相鄰兩格**（不限大、小）；亦得承租**無障礙位（單格）**。
   志願填想要的起始編號即可，系統自動帶鄰格；湊不到相鄰對且無剩餘無障礙位則落選候補。
   重機不適用「志願小位」；如住戶於重機列勾選志願小位，受理人員應提醒確認。
   **志願小位限每戶第 1 輛一般機車**（辦法伍二（五）本就只寫第一輛）：第 2 輛、第二張表都沒有此欄，一律進抽籤。
   櫃台受理志願小位流程：住戶對照平面圖填小位號 → 櫃台查指派維護頁／小位名冊確認未被登記 → 勾「號碼未被登記、已登入小位名冊」簽名 → 登錄系統時直接指派該小位。
   同一小位先到先得，後到者請改填其他小位；小位足額時「志願小位」只能改走抽籤。
4. **社會住宅戶**（Q7）：勾選後**限承租公益設施車位**（機車 1–7、92–104；自行車 114–118），
   免填車位志願序。惟**無障礙位不分社宅身分**——社宅之行動不便者仍可循無障礙優先配給。
5. **車位志願序（戶層級）**：全戶共用一份，**與登記車輛數無關**。抽出順序號後，依序分發
   「志願中仍剩的最高志願」（大學分發式）；多台車輪到時各自從同一份清單取最高可得者。
   志願填越多越能避免落空。
6. **填無效或空白車位志願**：視同未表達偏好——若有勾「電腦選號」由系統自動配本棟靠電梯
   剩位，否則保留待事後自選／候補。受理人員登錄時應剔除非該車種可停的車位編號
   （如一般車填到無障礙位、一般戶填到公益位）。
7. **自行車**：不排志願、隨機配位、不收費；抽中後簽承諾書並領識別貼紙。純自行車戶因無
   車牌不能線上登入，**電話務必留存**，日後異動一律由管理中心協助辦理。
8. **社區工作人員**（2026-08-26 定：共用本表）：勾「身分別＝社區工作人員」，並勾表末之知悉事項一行。
   ⚠️ **登記表不收完整承諾事項**——讓出、離職繳回等義務發生在「配得車位之後」，登記時尚無車位可讓，
   簽了亦不增拘束力（辦法本即有效）。完整承諾書應於配位後另簽（辦法伍二（十二）明定「應簽立承諾書」，
   惟現行四個附件均無此範本 → **建議增訂為附件五**，見 TODO）。
   與住戶**同梯登記、同樣可填志願**，但**配位排在所有住戶之後**——辦法伍二（十二）限制的是配位
   時點（「停車資格程序完結後如有剩餘車位」），非登記時點。**只要還有住戶未配得車位（第 1 輛落選
   且全戶無位），工作人員一律暫緩、不先占位**。免收費、不得申請公益位與無障礙位、住戶申請時
   無條件讓出。引擎已實作（`distribute.js` 最後一輪、`REASON.STAFF_PENDING`）。
