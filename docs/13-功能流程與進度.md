## 住戶流程

- ✅ 看說明 / 管理辦法 — `rules.html`
- ✅ 線上登記（或紙本，物業代登）— `RegisterView` + Supabase（已登入點「登記」自動進編輯）
- ✅ 選位填志願 — `SelectView`（地圖排志願 → **已存 Supabase**）
- 🔄 登入查結果 — `MeView`（登入 ✅、重整保持登入 ✅；**抽籤結果回填住戶尚未做**）
- ⬜ 簽約繳費（Phase II）

## 物業流程（核心閉環：登記 → 抽籤 已端到端可跑）

- ✅ 收登記（線上 + 紙本併冊、去重、衝突列出）— `registry`
- ✅ **匯出登記名冊** — `scripts/export-roster.mjs`（service_role 本機撈全戶 → `private/roster-*.csv`，gitignored；不開公開全個資端點）
- ✅ **匯入 + 跑抽籤/分發** — `AllocateView`：匯入名冊 CSV → 設種子 → `distribute` → 結果/落選/監察 log/**重抽**
- ⬜ 公告 + 匯出結果 — `ExportView`（匯出核心 `result.js` ✅，缺 UI）
- ⬜ 收繳費 / 候補遞補 — `ResultView`（Phase II）

## 核心閉環依賴鏈（登記 → 抽籤 已打通）

1. 登記 ✅
2. → 選位志願（存 Supabase）✅
3. → **匯出名冊** `export-roster.mjs` → CSV ✅
4. → **匯入 AllocateView** → 跑 `distribute` ✅
5. → 結果：**回填 `MeView`（住戶）⬜** + **`ExportView` 下載（物業）⬜（核心 ✅）**
6. → 繳費 / 候補（Phase II）

> 1–4 已端到端可跑（用「匯出名冊 CSV → 匯入抽籤頁」當橋，刻意不開公開全個資端點）。**剩餘缺口收斂到「結果落地」**：回填住戶 + 物業下載。

## 三介面分工（避免重疊）

- `MeView` ＝ 住戶看**自己**（登入、唯讀）
- `ExportView` ＝ 物業看**全部** + 下載 CSV（Phase I 兼結果預覽）
- `ResultView` ＝ **Phase II** 繳費狀態維護 + 候補遞補（屆時才與匯出分流）
