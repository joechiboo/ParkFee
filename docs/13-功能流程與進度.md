## 住戶流程

- ✅ 看說明 / 管理辦法 — `rules.html`
- ✅ 線上登記（或紙本，物業代登）— `RegisterView` + Supabase（已登入點「登記」自動進編輯）
- ✅ 選位填志願 — `SelectView`（地圖排志願 → **已存 Supabase**）
- 🔄 登入查結果 — `MeView`（登入 ✅、重整保持登入 ✅；**抽籤結果回填住戶尚未做**）
- ⬜ 簽約繳費（Phase II）

## 物業流程（核心閉環：登記 → 抽籤 → 結果 CSV 已端到端可跑）

> 管理員登入：戶號 `admin` ＋ 車號 `樂菲莊園`（前端特例 → `is_admin`；nav 出現「🔧 管理」）。
> 配位頁 `/allocate` 與維護頁 `/seat-admin` 限**管理員或本機(dev)**進入。

- ✅ 收登記（線上 + 紙本併冊、去重、衝突列出）— `registry`
- ✅ **匯出登記名冊** — `scripts/export-roster.mjs`（service_role 本機撈全戶 → `private/roster-*.csv`，gitignored）或後台 SQL Download CSV（見 doc 14）
- ✅ **車位鎖定維護** — `SeatAdminView`：地圖點選鎖定（保留/維修/已私下承租）→ 寫 Supabase `locked_seat`；抽籤排除、選位不可選、**跨裝置**
- ✅ **匯入 + 跑抽籤/分發** — `AllocateView`：匯入名冊 CSV → 設種子 → `distribute` → 結果(順序號連續排序)/免抽分流/落選/監察 log/**重抽** → **⬇ 下載配位結果 CSV**
- ⬜ 完整結果頁 / 公告 — `ExportView`（下載核心已在 AllocateView；看全部 UI 待做）
- ⬜ 收繳費 / 候補遞補 / 指派無障礙·小位給戶 — `ResultView`（Phase II）

### 🔄 / ⬜ 剩下

- **結果回填 `MeView`**：抽籤結果寫回 Supabase → 住戶登入看自己分到哪（🔄，最高 CP）
- **無障礙／小位改物業指派**：維護頁現只「鎖定」；要能「指派車位給戶（戶號→位→繳費）」才算移出抽籤。在那之前 distribute 仍自動分這兩類（顯示「免抽已定」），功能無誤（⬜）

## 核心閉環依賴鏈（登記 → 抽籤 已打通）

1. 登記 ✅
2. → 選位志願（存 Supabase）✅
3. → **匯出名冊** `export-roster.mjs` → CSV ✅
4. → **匯入 AllocateView** → 跑 `distribute` ✅
5. → 結果：**物業下載配位結果 CSV ✅（AllocateView）** + **回填 `MeView`（住戶線上看自己）⬜**
6. → 繳費 / 候補（Phase II）

> 1–5（物業端）已端到端可跑：匯出名冊 → 匯入抽籤 → distribute → 下載結果 CSV（橋接有測試鎖定）。
> 另：物業可先在 `/seat-admin` 鎖定保留位（上雲、跨裝置）→ 抽籤自動排除。
> **剩餘主缺口：結果回填住戶線上（MeView）。**

## 三介面分工（避免重疊）

- `MeView` ＝ 住戶看**自己**（登入、唯讀）
- `ExportView` ＝ 物業看**全部** + 下載 CSV（Phase I 兼結果預覽）
- `ResultView` ＝ **Phase II** 繳費狀態維護 + 候補遞補（屆時才與匯出分流）
