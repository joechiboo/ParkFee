## 住戶流程

- ✅ 看說明（白話時序、兩條配位路徑、FAQ）— `rules.html`
- ✅ 查管理辦法條文 — `BylawView`（nav「辦法」→ `/bylaw`）：頁籤切「現行辦法」／「修訂草案（對照表＋標紅全文）」。條文由 `scripts/build-bylaw.mjs` 從 [05](05-停車場管理辦法.md)、[19](19-辦法修訂草案.md) 轉 HTML（`npm run build` 會自動重生），docs 內部註記用 `<!-- web:skip-start/end -->` 包起來即不上網
- ✅ 線上登記（或紙本，物業代登）— `RegisterView` + Supabase（已登入點「登記」自動進編輯）
- ✅ 選位填志願 — `SelectView`（地圖排志願 → **已存 Supabase**）。入口：**登記完成畫面 CTA**「🗺️ 下一步：選車位志願序」/ MeView 按鈕 / 首頁流程 step2（2026-06-25 補回引導，原本只藏在 MeView）
- ✅ 登入查結果 — `MeView`：登入/重整保持登入 ✅；**抽籤結果回填**（車位/應繳/簽約期限/未中候補）✅（物業發佈後即可查）
- ✅ 查結果/繳費狀態 — `ResultView`（/result）：登入後看**每台車的配位+繳費狀態**（已登記·待配位 → 待繳費 → 已繳費確認 / 候補）+ **流程說明常駐**；與 MeView 共用登入（2026-06-24）
- 簽約繳費 — **線下臨櫃**（辦法定為唯一須本人到管理中心的環節：驗行照＋簽約＋繳一年）。✅ 系統支援已足：應繳/簽約期限顯示（MeView/ResultView）、物業標記已繳（洞①）、住戶已繳確認（ResultView）。🔴 線上收款管道待 Q5；⬜ 退費試算＋候補遞補 Phase II

## 物業流程（核心閉環：登記 → 抽籤 → 結果 CSV 已端到端可跑）

> 管理員登入：戶號 `admin` ＋ 車號 `樂菲莊園`（前端特例 → `is_admin`；nav 出現「🔧 管理」）。
> 維護頁 `/seat-admin` 與 dev 專區 `/dev` 限**管理員**進入；配位頁 `/allocate` **公開**（預設跑範例 demo，鄰居可玩、看演算法）。真實名冊匯入只在 dev 專區（個資不進公開頁）。

- ✅ 收登記（線上 + 紙本併冊、去重、衝突列出）— `registry`
- ✅ **匯出登記名冊** — `scripts/export-roster.mjs`（service_role 本機撈全戶 → `private/roster-*.csv`，gitignored）或後台 SQL Download CSV（見 doc 14）
- ✅ **車位指派維護** — `SeatAdminView`：地圖點位 → 填車號/車種/類型/**繳費** → 指派並鎖定（保留/志願小位/無障礙/維修）；抽籤排除、選位不可選、**跨裝置**。安全分流：車號/繳費寫 `vehicle`(deny-all)、id 寫 `locked_seat`(公開)
- ✅ **跑抽籤/分發** — `AllocateView`（**公開**，預設 20 戶範例 demo）：設種子 → `distribute` → 結果(順序號連續排序)/免抽分流/落選/監察 log/**重抽** → **⬇ 下載配位結果 CSV** → **📢 發佈**(限管理員)。**真實名冊匯入**移到 dev 專區（抽籤日匯入 → 共用 store → 回此頁大螢幕現場抽）
- ✅ 公告 / 結果輸出 — **公告走「⬇ 下載配位結果 CSV（Excel 開）」**(AllocateView)；住戶線上查走 MeView。**`ExportView` 已刪除**（2026-06-24：檔案/路由/nav「匯出」/首頁 step4 一併移除；eTag 白名單匯出移入 Phase II）
- ✅ **標記中籤大位已繳（洞①）已做**：`assign-seat` 的 `list` 改撈 `locked_seat` ∪ `vehicle 已分配` → 中籤大位顯示在維護頁（琥珀「抽籤分配」佔用）；點下去自動帶車號、勾「已繳費」→「指派並鎖定」寫 `vehicle.已繳費=true` → 住戶頁轉「已繳費確認」。⚠️小wrinkle：標繳後該位會一併進 `locked_seat`（變紅、出現解除鈕）/ 候補遞補仍 Phase II
- ✅ **巡邏稽核（含相機 OCR）**（2026-06-27）— `PatrolView`：掃／輸入車牌 → 顯示該車「應停車位／車種／繳費」→ 人工核對是否停對位（不顯示戶號）。OCR＝**onnxruntime-web（RoboEye 路線）**：DBNet 文字偵測 + en\_PP-OCRv3\_rec 辨識（模型自架 GitHub Pages、ort 走 jsdelivr CDN）；**先偵測文字行、挑「6-7 碼」那行** → 解兩行電動車牌；查無＝可能違停。`CamScanner.vue` + `src/lib/ocr.js`

> 🔜 **下週工作（細節見 [09-配位流程設計.md](09-配位流程設計.md)「下週工作」）**：① **車位分區工具**（B1 地圖圈選 → 棟別／電梯區／可否配位） ② **電腦選號**（志願落空＋勾選 → 自動配「本棟·靠電梯·剩餘」位；沒勾 → pending）。「電腦選號」取代舊「志願落選保底／物業代選」；一戶保底一位但未登記戶名額釋出。
