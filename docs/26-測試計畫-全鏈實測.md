## B 段：手動測試流程（瀏覽器）

> 站台 <https://joechiboo.github.io/ParkFee/>（或本機 `http://localhost:5173/ParkFee/`）
> ⚠️ **兩者連同一個 Supabase**，沒有測試庫 → 一律用下列測試身分，測完照階段 7 清除。

### 測試身分一覽（照這個填，清除 SQL 才掃得到）

| 身分 | 戶號 | 車號 | 用途 |
|---|---|---|---|
| 一般戶·重機 | `S1-991` | `TEST-001` | 驗重機相鄰兩格 |
| 社宅戶 | `S1-992` | `TEST-002` | 驗只能選公益位 |
| 工作人員 | 填「測試員」→ 存成 `員工-測試員` | `TEST-003` | 驗前綴自動補、選位限制、配位排最後 |

---

### 階段 1 · 一般戶登記（重機）

1. 開站台 → 確認左上角是「**樂菲莊園**」（不是 ParkFee）＝跑的是新版
2. 進「登記」→ 戶號 `S1-991`、電話 `0912345678`
3. 車輛第 1 台：車號 `TEST-001`、車種選「**重機（250CC 以上）**」
4. 送出

**預期**：出現綠色「✓ 登記完成」，列出「第 1 台 · TEST-001 · 重機」。
**不對的話**：若顯示「請檢查網路」→ 是錯誤訊息被吞（8/27 修過，回報我）。

### 階段 2 · 排志願（驗電腦選號預設）

5. 按「🗺️ 下一步：選車位志願序」
6. **先看右側「電腦選號」是否已打勾** ← 新預設（9/01 改）
7. 在地圖上點 3–5 格（點的順序＝志願序）→ 按「儲存志願序」

**預期**：① 電腦選號**預設打勾** ② 沒有多餘的 ☑ 符號 ③ 存檔顯示「✓ 已儲存到後端」。

### 階段 3 · 社宅戶（驗公益位限定）

8. 回「登記」（或先在 `/me` 登出）→ 戶號 `S1-992`、車號 `TEST-002`、車種一般
9. **勾「社會住宅住戶」** → 送出 → 進選位頁

**預期**：地圖上**只有金圈公益位可以點**（1–7、92–104），其餘一般位點不動；
圖例「可選」只列公益位。

### 階段 4 · 工作人員（驗前綴＋選位限制）★ 新功能

10. 回「登記」→ **先勾「社區工作人員」**
11. 觀察戶號欄提示是否變成「直接打姓名即可，例：陳大明」
12. 戶號欄**只打「測試員」**（不要打員工-）、車號 `TEST-003`、車種一般 → 送出

**預期**：完成頁顯示戶號為「**員工-測試員**」＝前綴自動補上。

13. 進選位頁

**預期**：① **金圈公益位點不下去** ② **無障礙位點不下去** ③ 圖例「不可選」列出
「公益（社宅戶專用）」與「無障礙（保留給行動不便住戶）」 ④ 頁首有橘字說明
「配位排全體住戶之後、住戶未配完時暫緩」。

### 階段 5 · 管理員載入名冊

14. `/me` 登出 → 以戶號 `admin`、**車號欄填管理員密碼**登入
15. 確認導覽列出現管理入口（🔧 管理／配位／🛠 dev）

**5a · 正案路徑（Dashboard → CSV → 匯入）**

16. Supabase Dashboard → SQL Editor → 貼 [docs/14 附錄](14-抽籤作業手冊.md)的 SQL → 執行 → 右上 **Download CSV**
17. 站台 `/dev` →「④ 匯入真實名冊」→ 選剛下載的檔

**預期**：`/allocate` 頂端顯示「**✓ 已載入…**」且**戶數與 Dashboard 查出的一致**。

**5b · 備案路徑（一鍵載入）★ 新功能**

18. `/dev` →「清除匯入（回範例）」→ 回 `/allocate`
19. 按藍色「**⬇ 載入真實名冊**」

**預期**：頂端變成「✓ 已載入…Supabase 即時名冊 · N 戶 / M 台」，**戶數與 5a 相同**。

### 階段 6 · 抽籤與驗證

20. 種子填 `手動測試-0902` → 按「執行抽籤」
21. 下載「**內部版 CSV**」

**逐項核對**：

| 檢查 | 怎麼看 | 預期 |
|---|---|---|
| 重機相鄰 ★ | CSV 找 `S1-991` 的車位編號（形如 `123、124`），對照結果地圖 | **兩格實體相連**，非隔走道／轉角／跨排 |
| 社宅 | 找 `S1-992` | 車位編號落在 1–7 或 92–104 |
| 工作人員 ★ | 找 `員工-測試員` | 若仍有住戶落選 → 狀態「暫緩」；否則配到一般位、**應繳 0 元** |
| 順序號 | 整份看 | 連續不跳號、無重複 |
| 鎖定位 | 對照鎖定清單（44 格） | 完全沒被配出去 |

22. 再下載「**公開版 CSV**」

**預期**：`員工-測試員` **不在公開版裡**（工作人員公告隱藏）。

### 階段 7 · 發佈、查詢、還原

23. 按「發佈結果」→ 登出 → 以 `S1-991` + `TEST-001` 登入 `/me`

**預期**：看得到自己的車位編號與應繳金額。

24. 以 admin 登入 → `/dev` → 「**②½ 清除配位結果（保留住戶資料）**」

**預期**：住戶再登入時已無車位，登記資料仍在。

25. **刪除測試資料**：`/dev`「② 清除測試資料」只刪 9xx 戶號 → `S1-991`／`S1-992` 會被清掉；
    `員工-測試員` 不符 9xx 規則，需用下方 SQL 補刪。
