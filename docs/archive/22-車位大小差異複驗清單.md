# B1 車位資料：竣工圖重建紀錄與待複驗清單

最後更新：2026-08-20

## 一、已完成：底圖與座標改用竣工圖重建

原本的底圖與座標描自 `docs/A2-5 地下一層平面圖.pdf`（舊版）。經比對，該版與竣工圖
`docs/A205_B1平面圖.pdf`（新北市建照電子副本，107店建字第372號）在 **90/655 個車位**上位置不同，
最大差距 59pt ≈ **4.2 公尺**，且**車位編號歸屬完全不同**（例：舊圖標 602 的位置，竣工圖標 590）。

已改為以竣工圖為準重建：

| 項目 | 作法 |
|---|---|
| 底圖 | 由竣工圖渲染 4768×3368，並去除粉紅浮水印（`scripts/rebuild-basemap.mjs`） |
| 機車位座標 655 格 | 取竣工圖向量記號中心（CAD 精度），非人工點放 |
| 自行車位座標 164 格 | 同上，取六邊形記號中心 |
| 編號指派 | **616 格直接判讀竣工圖印在圖上的號碼**；其餘 39 格用位置＋大小雙重約束補完 |
| 大小分類 | 以 2026-08-19 現場實勘（陳進茂）為準 |

**驗證結果**：圖面記號的大小與現場實勘**只差 143、144、145 三格**，正是經理指出的竣工圖已知誤差。
數量對帳：大車位 317 + 無障礙 8 = 325、小車位 330，合計 655 —— 與經理現場清點數字完全一致。

### B. 號碼無法從圖上直接判讀、靠推算補完的 39 格

這些格子的字形被圖面線條或無障礙標誌壓到，程式讀不出號碼，改用「位置＋大小」推定。
推定結果與實勘分類一致，但仍建議現場看一眼**號碼牌是否對得上**：

```

```

其中 **105–108、194–197** 是 8 格無障礙車位（號碼被輪椅圖示蓋住），優先確認。
