## 1. 12/2 出帳

### 1.1 前置（12/1 晚或 12/2 早）

1. **確認測試帳單都刪了**：社區幫「繳管理費 → 管理費列表」清除所有條件，搜 `H3-297`（自家自測 1,200 元）與 `H6-293`（11/3 誤掛的 1,200 元、9/17 經理代匯的 2,400 元）。還在的都刪掉，否則正式帳單會多掛一張。
2. `node scripts/check-roster.mjs` 跑到乾淨：測試戶（`員工-測試`／`員工-Z*`／`DEMO-*`）全清、衝突 0。
3. `node scripts/export-roster.mjs` 匯出登記名冊到 `private/roster-2026-12-01.csv`。

### 1.2 產檔

```powershell
node scripts/build-shequbang-import.mjs `
  --fee private/shequbang/payment-template-20261103-big5.csv `
  --roster private/roster-2026-12-01.csv `
  --announce 2026-12-01 --due 2026-12-10 `
  --out private/社區幫匯入-2026-12-02.csv
```

- `--fee` 是 11/3 從社區幫下載的範例檔，只拿來查門牌，不用等物業月結檔。
- `--roster`＝**「有登記就算錢」**：每台依車種計費（一般 1,200／重機 3,600／自行車 0 不出帳），沒配到位、重機還沒抽的都照收；社宅戶自動跳過。
  經理若改口「配到才收」，改用 `--result <配位結果.csv>`，其餘不變。
- 先加 `--dry` 看摘要：出帳戶數、計費台數、應收總額、社宅跳過清單。
- ⚠️ **總額不符或有戶查無門牌時，腳本印 ❌、結束碼 1，但 `--out` 的檔案仍會寫出**（內容缺那些戶）。看到 ❌ 就不要上傳，回頭查名冊。是否改成失敗就不寫檔待決定，見 TODO 檔首 C 段。
- 收費類別預設「116年度機車位清潔費」，立帳日＝當天，期限 12/10。

### 1.3 上傳

1. 社區幫「繳管理費 → 管理費列表 → **新增繳費單 → 上傳檔案**」，選剛產的檔。
   ⚠️ 不是「帳單管理 → 建立帳單設定」，那會蓋掉每戶的週期管理費設定。
2. 上傳後把篩選清乾淨，收費類別選「116年度機車位清潔費」，核對：**張數＝腳本印的出帳戶數、總金額＝應收總額**。
3. 抽查三戶：門牌樓層對得上戶號（規則：社區幫 `#A1-375` 2 樓＝系統 `A2-1`，中間數字意義相反）、金額對得上登記台數。
4. 「再次通知」可以推播給住戶；要不要按由主委決定。

### 1.4 社宅與工作人員（腳本不出帳的兩群）

- **社宅 20 戶**：公益位由社宅單位自排，帳單掛社宅單位、按車計費，由物業另開；需社宅先給車輛清單。
- **工作人員（戶號 `員工-*`）**：沒有門牌，腳本會列進「查無門牌」擋下。物業要給一個掛帳門牌，或這幾張手動開。**12/2 前必須有答案**，這題從 9 月問到現在。

## 2. 12/11 繳費回查：把「誰繳了」餵回系統

### 2.1 社區幫匯出

管理費列表 → 清除條件 → 收費類別「116年度機車位清潔費」→「下載檔案」→ 存到 `private/shequbang/`。
檔案長這樣。11/3 的匯出檔只有一筆已繳的汽車清潔費，**機車位帳單與未繳列的匯出還沒實測**，所以下表標明每項的依據：

| 欄 | 值 | 怎麼讀 | 依據 |
|---|---|---|---|
| 住戶地址 | `S2-50-1樓` | 門牌＋樓層合併，拆開後走 `householdIdOf()` → `S1-2` | 匯出檔 |
| 收費類別 | `116年度機車位清潔費` | 一戶跨月合繳可能用逗號串多個類別，比對用「包含」 | 類別名見於畫面；逗號串接見於對帳單，列表未驗 |
| 繳費狀態 | 未繳＝`未繳費`；已繳＝繳費方式（如 `虛擬帳號`） | **不等於「未繳費」且非空即已繳**。⚠️ 若另有 `逾期` 等未繳狀態會被誤判成已繳，選項待確認 | `未繳費` 見於畫面、`虛擬帳號` 見於匯出檔 |
| 繳費備註 | 本例在帳單備註欄：`2026/05/29轉帳繳費500元` | 只供人工參考，程式不讀 | 匯出檔 |

Big5、每格外層多包一層 `="…"`（Excel 防呆），腳本讀入時剝掉。

### 2.2 餵回系統（✅ 2026-11-03 建；部署見 §2.4）

```powershell
# 1) 乾跑：只印已繳／未繳戶數、同戶部分未繳、對不到戶號的列，不寫
node scripts/import-paid-from-shequbang.mjs --file private/shequbang/payment-20261211-big5.csv

# 2) 確認無誤後套用（ADMIN_PASSWORD 由使用者輸入，不存 repo）
$env:ADMIN_PASSWORD='…'; node scripts/import-paid-from-shequbang.mjs --file private/shequbang/payment-20261211-big5.csv --apply
```

- 規則：收費類別**包含**「機車位」的列才看；繳費狀態非空且 ≠「未繳費」＝已繳；**同戶多張只要一張未繳就不標**，列出來人工判斷。
- 後端 `assign-seat op=pay` 按戶把該戶全部機車 `已繳費`＝true，每台記 **繳費來源＝「社區幫 2026-12-11」** 與 繳費時間（批次標的看得出來，與櫃台指派的「櫃台指派」區分）；稽核表記 `pay.batch`：來源、戶數、台數、查無戶號數，不記戶號清單。
- 維護頁 ✓繳 後面會顯示來源；標錯整批撤回：同一指令加 `--undo`。
- 系統查無的戶（社區幫有帳、系統沒登記）會印出來，通常是物業手動開的帳單，人工看。
- 第二輪「只分已繳者」（配位頁勾選）與維護頁「未繳費批次解除」都靠這個旗標。
- 櫃台收現金的，物業要在社區幫手動銷帳，狀態才會變；系統不另外收手工名單。**繳費狀態的真相來源只有社區幫**。
- 同步時機：12/11 一次，批次解除未繳前再重跑一次接住晚入帳的；第二輪若仍有 12/25 繳費期限，12/26 再跑一次。12/10 前系統沒有功能用到這個旗標，不必逐日更新。腳本可重跑，已標的戶會把來源與時間更新成最新一次，櫃台指派的「櫃台指派」字樣也會被蓋掉。

## 4. 財委對帳（對帳單下載）

對帳單是**銀行撥款對帳**，不是繳費清單：週日～週六一批，隔兩週週三撥款，只列走金流的筆（信用卡／虛擬帳號／超商／溢繳沖銷），**櫃台現金不會出現**。

車位費會落在兩批：

| 繳款週 | 預估撥款 | 對什麼 |
|---|---|---|
| 11/29–12/5 | 約 12/16 | 收費類別含「機車位」的社區實收合計 |
| 12/6–12/12 | 約 12/23 | 同上 |

- 社區實收＝帳單金額（信用卡、超商 10 元手續費由住戶付）；「溢繳沖銷」代收單位寫「社區」，是沖抵不是現金，入帳要扣掉。
- 一戶跨月合繳的列，收費類別會串成「10月管理費,11月管理費,機車位…」、金額是合計，機車位那部分要從明細拆。
- 兩批合計＋櫃台現金 ＝ 管理費列表裡已繳張數 × 金額，對上就結案。
