# Google 表單設計 — 機車車位登記

> 住戶自助登記用的 Google 表單規格，可直接照此建表。
> **目的**：免費、住戶熟悉、多人同時填無虞、自帶修改紀錄（稽核加分）。收完即一張試算表，匯出 CSV 餵進配位工具。
> **相關文檔**：流程與收費時機見 [00-年度作業時間線.md](00-年度作業時間線.md)；CSV schema 見 `HANDOFF.md` §8。
> **重要**：此表**只收登記資料，完全不碰金錢**。錢在抽中後臨櫃繳（辦法 伍二(六)）。

---

## 設計原則

1. **一戶一次送出**：辦法規定「每戶限登記一次，一次填齊」〔伍二(八)〕。用 Google 表單的「**前往區段**」做第 2、3 輛的分支。
2. **不收身分證號**：守住隱私原則，只收必要欄位。
3. **欄位對齊 schema**：表單欄位 → 匯出後能映射回 `戶號, 車號, 車種, 第幾輛, 身障, 志願小位, 登記時間, 聯絡電話`。
4. **驗證前置**：能在表單擋的格式（戶號、車號、電話）就用「回應驗證」擋，減少後端清理。

---

## 表單結構

### 開頭說明（表單標題與描述）

```
標題：樂菲莊園 機車車位登記（115 年度）
描述：
・登記期間：11/15–11/30，逾期未登記以棄權論。
・每戶限登記一次，請一次填齊想登記的所有機車（第 1、2… 輛）。
・本表只做登記，不收任何費用；抽中車位後再到管理中心臨櫃簽約繳費。
・登記時請備妥行車執照（供查驗車號）。
・本表不蒐集身分證號。
```

### 區段 1 — 住戶資料

| 題目 | 類型 | 必填 | 驗證 / 備註 |
|---|---|---|---|
| 戶號 | 簡答 | ✅ | 回應驗證 → 正規表達式，鎖格式（例如 `棟-樓-戶`，依社區實際格式） |
| 聯絡電話 | 簡答 | ✅ | 回應驗證 → 數字 / 電話格式 |

### 區段 2 — 第 1 輛機車（必填）

| 題目 | 類型 | 必填 | 對應 schema / 備註 |
|---|---|---|---|
| 車號 | 簡答 | ✅ | 正規表達式驗證車牌格式；匯入時再正規化（大寫、補連字號） → `車號` |
| 車種 | 單選 | ✅ | 選項：`一般（≤250CC）` / `重機（250CC↑，紅／黃牌）` → `車種` |
| 是否需要無障礙車位 | 單選 | ✅ | 選項：`是` / `否`。身障者優先〔伍二(三)〕 → `身障` |
| 是否志願登記小位 | 單選 | ✅ | 選項：`是` / `否`。志願小位免抽、依登記順序選位〔伍二(五)〕 → `志願小位` |
| **還要登記第 2 輛嗎？** | 單選 | ✅ | `要` → 前往區段 3；`不要` → 前往提交 |

> 此區段所有題目 → 匯出列為「第幾輛 = 1」。

### 區段 3 — 第 2 輛機車（選填，由分支進入）

| 題目 | 類型 | 必填 | 備註 |
|---|---|---|---|
| 車號 | 簡答 | ✅ | 同上 |
| 車種 | 單選 | ✅ | 同上 |
| 是否志願登記小位 | 單選 | ✅ | 同上 |
| **還要登記第 3 輛嗎？** | 單選 | ✅ | `要` → 前往區段 4；`不要` → 前往提交 |

> 此區段 → 「第幾輛 = 2」。第 2 輛起採登記抽籤制〔伍二(六)〕。

### 區段 4 — 第 3 輛機車（選填，由分支進入）

結構同區段 3（車號 / 車種 / 志願小位），結尾直接前往提交。
> 「第幾輛 = 3」。第 3 輛以上有剩餘再依序辦〔伍二(七)〕。

### 結尾確認文字

```
送出即表示已詳閱並同意「社區地下室停車場管理辦法」相關規定。
登記資料將用於抽籤配位；抽中後請於公告後 5 日內到管理中心簽約並一次繳一年費用，
逾公告後 10 日未辦妥視同放棄，由候補遞補。
```

## 設定建議

- **收集回應的 Email**：可關閉（不強制登入），降低住戶門檻；若要可編輯回應，再評估開啟。
- **回應自動進試算表**：開啟「連結至試算表」，回應即時匯入一張寬表。
- **進度列**：開啟，讓住戶知道還有幾段。
- **限一回應**：⚠️ 不建議依賴。它需登入 Google 且只能擋「一帳號一次」，擋不住戶號 → 改在匯入時依戶號去重。

---

## 表單做不到、要靠匯入時處理的 3 件事

匯入工具（純前端）負責清理，Google 表單本身做不到：

1. **寬轉長**：一戶一列（第 1/2/3 輛佔不同欄）→ 拆成 schema 要的「一列一輛」。
2. **車號正規化**：統一大寫、補連字號、修 O/0 I/1 B/8（即 `normalizeTWPlate`），抽籤前先乾淨。
3. **同戶去重**：同戶號重複送出 → 保留時間最新一筆，並列衝突清單供人工確認。

## 匯出 → 匯入映射表

Google 試算表（寬表）匯出 CSV 後，工具轉成 schema：

| 寬表欄（範例） | → schema 欄 |
|---|---|
| 時間戳記 | `登記時間` |
| 戶號 | `戶號` |
| 聯絡電話 | `聯絡電話` |
| 第 1 輛·車號 / 車種 / 身障 / 志願小位 | `車號`/`車種`/`身障`/`志願小位`，`第幾輛=1` |
| 第 2 輛·車號 / 車種 / 志願小位 | 同上，`第幾輛=2`，`身障` 沿用該戶值 |
| 第 3 輛·車號 / 車種 / 志願小位 | 同上，`第幾輛=3` |

> 是 / 否 → Y / N；車種文字 → `一般` / `重機`。

## 決策紀錄

1. ✅ **戶號格式**（2026-06）：八棟 **A–H**（住戶）＋ **S**（店家），格式為「棟+樓-戶」，例 `H3-6`、`S1-2`。驗證 regex：`^[A-HSa-hs][0-9]{1,2}-[0-9]{1,2}$`。
2. ✅ **行照照片上傳**（2026-06）：**不收**。表單免登入、不存雲端照片，行照改現場/臨櫃查驗。
3. **第幾輛上限**：表單預設做到第 3 輛（腳本 `CONFIG.maxVehicles` 可改）。
4. **重機與志願小位**：重機佔雙位通常不適用「志願小位」；目前仍保留該題，受理/匯入時提醒確認。
