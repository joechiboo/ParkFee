## 修訂對照表

### 1. 參二（四）（五） 大／小機車位數量（Q11：現場清點落差）

| | 條文 |
|---|---|
| 現行 | （四）一般（大）機車位 320 個（公益編號：2、3、6、7、97、98、103、104）。<br>（五）一般（小）機車位 327 個（公益編號：1、4、5、92、93、94、95、96、99、100、101、102）。 |
| 修訂 | （四）一般（大）機車位 **＿＿＿** 個。（五）一般（小）機車位 **＿＿＿** 個。（公益編號均同現行） |
| 說明 | 依現場清點結果修正大/小分項，**機車位總數 655 個不變**；確切數字**待經理核對（8/22）後填入** |

### 2. 肆五 重機停放（Q6：不設專區、穿插＋可停無障礙）

| | 條文 |
|---|---|
| 現行 | 五、本社區機車停車位（250CC 以下），為機車專用停車位，嚴禁停放其他車種車輛，在本社區機車位足額之條件下，250CC 以上重型機車，得停放於雙機車位。 |
| 修訂 | 五、本社區機車停車位（250CC 以下），為機車專用停車位，嚴禁停放其他車種車輛。在本社區機車位足額之條件下，250CC 以上重型機車得承租**相鄰之兩個機車位**（不限大、小機車位），**並得承租無障礙機車位**；重機承租之無障礙機車位遇行動不便之身心障礙者申請時，依伍二（四）規定無條件退租。 |
| 說明 | 「雙機車位」明確化為「相鄰兩格、不限大小」；開放重機承租無障礙位，身障者優先權由伍二（三）（四）既有規定保障。**保留 2 格（108、194）屬執行做法**（locked_seat 鎖定），不入條文，日後增減免修法 |

### 3. 伍二（五）（六）（十） 分發方式明文化（Q2）

| | 條文 |
|---|---|
| 現行 | （五）…直接採取抽「車位資格」…（六）…登記住戶抽車位號碼…決定次年停放資格、車位號碼，及未抽中者之候補順序…（十）車位分配方式：採取抽「車位資格」。 |
| 修訂 | （五）（六）之「抽車位號碼／抽車位資格」修改為：「登記時填寫**車位志願序**；抽籤抽出**順序號**，依順序號由小至大，分發各戶志願中尚餘之最優先車位；**順序號並兼作候補順序**，有車位釋出時依序遞補。」（十）車位分配方式：**採填志願、抽順序號、依序分發**。 |
| 說明 | 候補序＝順序號（原 Q1 已併入）；志願小位免抽依登記序當場選位之規定維持不變 |

### 4. 伍二（八） 登記與查驗（Q2 附帶＋8/16 決議）

| | 條文 |
|---|---|
| 現行 | （八）每戶限登記一次，登記時請出示行車執照供查驗及登記車號。 |
| 修訂 | （八）每戶限登記一次，登記得以**線上或紙本**方式辦理並登記車號；證件查驗改於**繳費簽約時**辦理，出示**行車執照或身分證明文件擇一**即可。 |
| 說明 | 部分住戶行照不易取得；查驗時點與實務對齊 |

### 5. 伍二（二） 社會住宅（Q7：公益位專用）

| | 條文 |
|---|---|
| 現行 | （二）社會住宅承租戶單獨辦理。 |
| 修訂 | （二）社會住宅承租戶單獨辦理，**限承租公益設施機車位**（編號如參二所列）；公益設施機車位**不開放一般住戶承租**。 |
| 說明 | 公益位用途查明＝保留社會住宅住戶使用 |

### 6. 伍二 增訂（十三） 換位（Q14；區權會追認）

| | 條文 |
|---|---|
| 現行 | （無） |
| 修訂 | （十三）承租戶於完成繳費簽約後，得向管理中心申請**換位至無人承租之車位**，**每次**應繳納作業費**新臺幣壹佰元整**，並開立流水號收據存入社區專戶；**申請過於頻繁致影響管理作業者，管理中心得不予受理**。 |
| 說明 | **不設次數上限**（原案「一戶一次」不採），改以「每次收費＋管理中心得拒絕頻繁申請」達成決議之「不可太頻繁」。例會決議通過即實施，列入下次區權會追認；物業於維護頁人工辦理 |

### 7. 伍二（十二） 工作人員（Q15：免費）

| | 條文 |
|---|---|
| 現行 | （十二）停車資格程序完結後如有剩餘車位，社區工作人員得以相同條件使用；惟應簽立承諾書… |
| 修訂 | （十二）停車資格程序完結後如有剩餘車位，社區工作人員得申請使用，**免收維護管理費**；惟應簽立承諾書…（其餘文字不變） |
| 說明 | 「相同條件」費用疑義以決議定為免收 |

### 8. 費用名稱統一為「維護清潔費」（法源：財務辦法）

| | 條文 |
|---|---|
| 現行 | 伍二（六）「一次性繳納一年**維護管理費**」；柒二「停車**維護管理費**繳費標準」；<br>【附件一】五「**承租金額**：每一機車停車位每月新臺幣 100 元…一次繳清**租金**」。 |
| 修訂 | 上開「維護管理費」「承租金額」「租金」一律修正為「**維護清潔費**」。 |
| 說明 | ① 辦法柒一本文即為「汽（機）車車位**維護清潔費**」，內部用語不一；<br>② 財務管理辦法柒二（二）入帳科目為「停車位**清潔費**收入」、壹拾二（一）4「所有公共設施出租，**均以清潔費名義作收入**」→ 統一名稱與財務辦法及實際入帳一致，避免以「租金」名義收費衍生課稅疑義。<br>③ 僅為名稱統一，**金額與繳納方式均不變**。 |

> 延伸（未納入本案，供委員參考）：辦法及附件一多處使用「承租／出租／退租」等租賃用語，如管委會認為有必要一併正名為「使用／申請／終止使用」，範圍較大，建議另案處理。
