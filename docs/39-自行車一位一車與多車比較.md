# 自行車位：一位一車與一位多車比較（2026-11-05）

住戶在 LINE 質疑「限停一輛」後整理，用於說明與討論。使用者本身支持一位多停，這份只整理事實與論點，不代表管委會立場。

## 條文現況

| 時間 | 內容 |
|---|---|
| 現行辦法 | 沒寫一格幾台。附件二只禁停自行車以外的車輛或雜物，陸三只禁超越車位 |
| 9/3 例會第 10 題 | 通過「不限制只停一輛，但以不超出停車格為原則」（6 票） |
| 10/8 例會 | 對照表列入「不限停放一輛」，整份 6 票通過 |
| 10/29 臨時會 | 手寫批註為整條劃叉（紙本決議欄空白）；經理對照表記為修訂成「限停放一輛，惟以不超出停車格線為原則」，8 票通過 |
| 11/05 | 經理傳來的最終版對照表仍是限停一輛 |

**不能解釋成「沒規定就是不限制」**：依紀錄不是被否決後回到沒寫，而是改成明文限停一輛。要改為多停，須在例會重新提案。正式會議紀錄尚未收到；如果紀錄寫的是「刪除」而非「修訂」，條文才回到沒有規定，但委員會剛拿掉開放的條文，仍要管委會解釋。

## 不要這樣主張

討論中已確認下列說法不成立：

- **「一位一車能分給較多戶」**：兩種做法的車位數相同，中籤戶數和機率也相同。
- **「多停讓第二台插隊」**：車位不夠時輪不到第二輪，多停沒有占走誰的位子。沒中籤的戶在兩種做法下都是零台。
- **「車位不夠時一位一車較公平」**：只是中籤與沒中籤的差距較小（1 台對 0 台，而非 2 台對 0 台），屬觀感，不是多分給誰。
- **「第二輪抽完有空格才開放多停」**：那時登記的車都有位子了，不需要多停。多停是車位不夠時才有用。
- **「機率 1/4」**：164 ÷ 655 約等於 1/4，等於假設每戶都登記；扣掉社宅 5 格與 20 戶，比例也差不多。實際機率要看登記戶數。

## 真正的爭點

多停不影響別戶的機率，所以重點是：**中籤家庭的方便，值不值得換來管理和使用上的代價？**

- 每戶可登記多台，沒有台數上限（伍三（四）；線上登記、引擎皆同），每台各抽各的，抽中一台為一格。
- 車位不夠時第二台輪不到第二輪，機車位也不能停自行車（肆十五），中籤戶的第二台要另找地方。

## 比較

| 項目 | 一位一車 | 一位多車 |
|---|---|---|
| 能停幾台 | 一格一台 | 可停更多，要看格子尺寸 |
| 車位分配 | 164 格，中籤戶停一台 | 164 格，中籤戶可多停，別戶不會因此少位子 |
| 同戶第二台 | 等第二輪，有剩才抽 | 可和第一台停同一格 |
| 取車與碰撞 | 不會被擋，碰撞風險較低 | 可能要先搬車，較易刮傷 |
| 空間與占位 | 停小車會浪費空間，但較難占位 | 空間利用較好，但可能放備用車、壞車（空置三個月收回已刪除） |
| 巡場與貼紙 | 一格一台，判定明確 | 要判斷壓線和車主，貼紙按台數發、登記表加台數欄 |
| 需求資料 | 沒中籤人數能反映缺口 | 部分需求被多停吸收，缺口較難估 |
| 日後調整 | 之後放寬，阻力小 | 之後收緊，要請住戶移車 |

管理影響與風險是推估，不是實測。

**一位一車還站得住的理由**：管理與使用面；另外，如果格子真的放得下兩台又能重畫，多出來的空間可以變成新車位放進抽籤，受惠的就包括沒中籤的戶。

**折衷方案**：同戶一格上限兩台，且不得超出格線。接近 9/3 提案單丙案（一格上限兩台），再加上限同戶，巡場看到第三台就算違規。

## 建議下一步

先實際量一格，用兩台成人車試停。目前手上沒有格子尺寸。

- 放得下：評估提案開放多停，或重畫格子增加車位。
- 放不下：維持一位一車。
