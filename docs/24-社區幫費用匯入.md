# 社區幫費用匯入 — 格式與產製規劃

> 目的：12/1 配位完成後，把**機車位維護清潔費**做成社區幫匯入檔收款。
> 格式依據：使用者提供之實際檔「第三屆管理費115年05月管理費.csv」（真實帳務資料，**已 gitignore 不進版控**，放本機根目錄）。
> 2026-08-24 建立。

## 1. 檔案格式（由範本檔逆推）

- **編碼：Big5、無 BOM**（非 UTF-8；匯出時須轉碼）。
- 一戶一列，全社區 656 戶（範本 657 列含表頭）。
- 欄位：

| 欄 | 內容 | 範例 |
|---|---|---|
| 住戶住址(門牌號) | `#棟-街號` | `#A1-375` |
| 住戶住址(樓層) | 數字 | `3` |
| 住戶住址(之) | 數字，無則 0 | `0` |
| 收費類別 | `YYYY年MM月管理費`（西元） | `2026年05月管理費` |
| 備註 | 空 | |
| 細項(列舉參考欄位) | 固定字串 | `#管理費#汽車清潔費#機車清潔費#附加費用` |
| 立帳通知日期 | `YYYY/M/D` | `2026/4/25` |
| 繳費期限 | `YYYY/M/D` | `2026/5/25` |
| 管理費 | 坪數 × 90 | `1757` |
| 汽車清潔費 | 汽車位數 × 500 | `500` |
| 機車清潔費 | 目前全 0 ← **我們要填的欄** | `0` |
| 附加費用 | 0 | `0` |

- 立帳約前月 25 日、繳費期限約當月 25 日。
- 2026 年 11 月（含）以後，交屋預繳管理費均已滿期，**無破月問題**，各戶金額規則化。

## 2. 費率（機車部分＝本系統產出）

| 項目 | 金額 | 依據 |
|---|---|---|
| 一般機車位 | **1,200 元／年**（一次繳清） | 辦法柒二 |
| 重機（相鄰兩格） | **3,600 元／年** | 辦法柒二 |
| 自行車位 | 0（不收費，不出帳） | 辦法柒二 |
| 工作人員剩餘位 | 0（免費，不出帳） | 修訂第 7 條 |
| 一戶多位 | 逐位加總 | |

## 3. 產製方式（建議：合併模式）

**script（待建）：`scripts/build-shequbang-import.mjs`**

輸入：
1. 物業提供的**當月管理費檔**（既有格式，管理費/汽車欄由物業產，我們不碰）
2. **配位結果 CSV**（12/1 產出：戶號、車位、車種、應繳金額）
3. **戶號 ↔ 門牌對照表**（由範本檔 657 列派生一次＋人工校對；ParkFee 戶號 `棟樓-戶別` ↔ 社區幫 `門牌號＋樓層＋之`）

輸出：同格式 Big5 CSV，**只把「機車清潔費」欄填上**（1,200／3,600 × 位數），其餘欄照物業檔原樣。

驗證：輸出總額 ＝ 配位結果應繳總額（例：401 台規模 ≈ 48 萬）；未配位戶必為 0；列數與物業檔一致。
