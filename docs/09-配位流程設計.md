# ParkFee — 配位作業流程設計（Phase I）

> 本文記錄「抽籤 → 選位 → 結果」的端到端流程設計與待決事項。
> 規則唯一事實來源：`docs/社區地下室停車場管理辦法.pdf`。本文如與辦法衝突，以辦法為準。
> 最後更新：2026-06-06。

## 階段切分

- **Phase I（進行中）**：配位核心 — 抽籤 → 選位 → 結果。
- **Phase II（延後）**：住戶線上登記表單（含車牌 OCR）、繳費系統、eTag 白名單匯出、巡邏稽核。

## 端到端流程（依辦法時程）

```
①登記期(11/15–11/30)
   住戶線上登記 → 名冊(戶號·車號·車種·第幾輛·身障·志願小位)
   辦法：一戶僅得先登記一個機車位；未登記者以棄權論               ✓ 規則已定
        │
        ▼
②抽籤＝電腦隨機抽選「順序號」（可重現：公告種子 / 執行時間 / 監察委員）
   Round 0 無障礙(身障優先, ≤8全配 / >8抽8未中併入R1)
   Round 1 一戶一位(志願小位免抽選小位 / 其餘抽資格＋順序號)
   Round 2+ 第二位起(辦法：如有剩餘再抽；需求≤剩餘全配, 超額抽+候補)  ✓ 引擎已做
        │
        ▼
③人工選位：中籤者依順序號逐一選剩餘車位（選課式，非自動指派）      ✅ 已定（決策 A）
        │
        ▼
④公告配位結果                                                  ✓ 結果頁待做
        │
        ▼
⑤簽約繳費（公告日+5日內；一般 1,200/年、重機 3,600/年）
   辦法：公告後 10 日內未辦妥視同放棄                            ❓ 是否進 Phase I（決策 B）
        │
        ▼
⑥放棄 → 候補遞補；空出車位回到池                                ❓ 流程/時機未定（決策 B）
        │
        ▼
⑦如有剩餘 → 回到 ②跑下一輪                                     ❓ 三輪時程未定（決策 C）
```

## 選位作業模式（2026-06-06 拍板）：填志願 + 統一分發

**像「大學考試分發入學」**：先填具體車位志願序 → 抽順序號 → 依序分發最高可得志願。全程可重現、無「搶位」併發問題。

1. **填志願**（登記臨櫃時，看地圖排序）：住戶從車位地圖挑**具體車位**，排出 `志願1、志願2、志願3…`。
   - 非排他：不同戶可填同一格為志願，衝突由後面的順序號裁決。
   - 志願小位快速道**不變**：免抽、登記時依登記順序當場選小位，不進此分發。
2. **抽籤**：抽出每戶「順序號」。
3. **自動分發（第一階段，可重現）**：依順序號由小到大逐戶，分到「該戶志願序中、目前仍剩的最高志願」。志願全被先順位取走者**暫時 pass、列入「落選名單」**，不中斷分發、續跑下一順位。**全程批次算完，不等住戶回應**。產出＝已配位名單＋落選名單＋剩餘車位。
4. **物業處理落選者（第二階段，待第一階段全部跑完）**：
   - 勾「**志願落選保底**」→ 物業從剩餘車位代配一個「**最靠近其棟別、且車種停得下**」的剩位（保證有位，符合辦法「保障一位」）。
   - 未勾 → 列**候補**，等前位放棄遞補或下一輪。
   - ⚠️ **取捨**：保底是「撿主分發後的剩位」，故高順序號但志願全落空者，**其保底位可能排在某些低順序號、但有明確志願者之後**。即本模型為「**先尊重所有人明確志願、再補落選**」，非「純順序號優先到底」。保底位的就近判斷屬物業裁量（fuzzy），不入可重現引擎。
5. **公告 → 繳費 → eTag。**

> 取代了先前「靠電梯+樓層偏好 + 現場微調」版本：偏好改為**具體車位志願序**，分發改為**統一一次算完**（不需現場逐一微調）。

**前置相依**：
- 登記要能填志願 → 看地圖選具體車位（線上或臨櫃輸入），存「戶號 → 志願序[車位編號…]」。改登記欄位/流程（02 表單、04 紙本、CSV schema HANDOFF §8）。
- 地圖要做到 **① 每格可點**（選具體車位）、**② 每格標「靠近哪棟」A–H/S**（志願落選保底用）→ 加深 [11-選位地圖實作.md](11-選位地圖實作.md) 的分區歸類（目前卡點）。

### 合規檢查（對辦法 伍、二）

**符合**：登記期、臨櫃驗行照〔(八)〕、無障礙優先〔(三)〕、志願小位免抽依登記序〔(五)〕、公開抽籤監察可重現〔(九)〕、保障一位〔(五)〕、分輪〔(六)(七)〕、繳費時程〔(六)〕。

**兩個待管委會處理**：
1. ⚠️ **用語落差**：辦法 (六)(十) 對車位號碼用「**抽**」字（抽車位號碼）；本模型號碼是「**填志願 + 依順序號分發**」決定，非隨機抽號。可主張符合精神（(五) 已允許「依順序選定號碼」），但建議**管委會以決議將「選課式志願分發」明文化**（辦法 捌「未盡事宜」、玖「可修訂」）。
2. ⚠️ **候補不能省**：辦法 (六) 明文「登記戶數 > 車位數量」時須定「候補順序」。本模型「志願落選→物業補靠近棟別剩位」只在仍有剩位時成立；需求 > 總供給時**強制要候補名單** → 對應決策 B，勿漏。
