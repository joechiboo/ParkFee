## 階段切分

## 選位作業模式（2026-06-06 拍板）：填志願 + 統一分發

**像「大學考試分發入學」**：先填具體車位志願序 → 抽順序號 → 依序分發最高可得志願。全程可重現、無「搶位」併發問題。

1. **填志願**（登記臨櫃時，看地圖排序）：住戶從車位地圖挑**具體車位**，排出 `志願1、志願2、志願3…`。
   - 非排他：不同戶可填同一格為志願，衝突由後面的順序號裁決。
   - 志願小位快速道**不變**：免抽、登記時依登記順序當場選小位，不進此分發。
2. **抽籤**：抽出每戶「順序號」。
3. **自動分發（第一階段，可重現）**：依順序號由小到大逐戶，分到「該戶志願序中、目前仍剩的最高志願」。志願全被先順位取走者**暫時 pass、列入「落選名單」**，不中斷分發、續跑下一順位。**全程批次算完，不等住戶回應**。產出＝已配位名單＋落選名單＋剩餘車位。
4. **志願全落空者處理（2026-06-27 改版：「電腦選號」取代物業手動代選；2026-07-24 定調）**：
   - **定位（2026-07-24）**：**自選志願為主、電腦選號僅是補救機制**——原則上希望住戶自己挑位，電腦選號給「不想再跑一趟、有位就好」的人。
   - **A. 有勾「電腦選號」** → 系統**自動**配一個「**屬本棟、靠近電梯、可配位、剩餘**」的車位（本棟無剩才往鄰棟）；依順序號處理、**可重現、進引擎**。不候補、不等下輪。
   - **B. 沒勾** → 先 **pending**，待主分發＋電腦選號都跑完、車位大勢底定後，**開放從剩餘車位自選——不用補錢**（免手續費）。
   - **已配位後要再異動**（不論志願中選/電腦選號/事後自選）→ 屬「換位」、**需補處理費**（金額與收費程序＝決策 Q14，例會決議）。
   - 「**一戶保底一位**」只保障**有登記**的戶；**未登記戶不占名額**，其容量釋出給其他有需要的鄰居（第二輛、工作人員等）。
   - ⚠️ **取捨**：電腦選號是「撿主分發後的剩位」，故高順序號但志願全落空者，其電腦選號位可能排在某些有明確志願的低順序號之後（先尊重明確志願、再電腦補位）。
   - 名稱沿革：原「志願落選保底／物業代選」→ 統一改稱「**電腦選號**」（強調是電腦自動、非物業手動）。
   - **候選池（2026-07-24 實作）**：電腦選號只配**大位**（小位＝志願小位自選快速道、無障礙＝R0 專用、重機區＝限重機，皆不硬塞）；各棟優先序＝`tower-priority.json`（2026-07-29 起以**使用者手排檔** `tower-order-manual.json` 為底、自動補新格＋借位均分），鎖定變動後重跑 `scripts/build-tower-priority.mjs`。

**重機專區（2026-07-29 定，待 Q6 例會追認）**：`321-349` 共 29 格標 `type=重機區`（非鎖定）。**只有登記有重機的戶**可在選位頁選區內格排志願；一般車/志願小位/電腦選號天然選不到。引擎重機輪＝志願中可湊**相鄰對**者優先、否則區內最低號相鄰對、無相鄰對→落選（HEAVY_SHORT）交物業。⚠️ 此段現場編號仍待核對（主檔盤點 26小+3大）。
5. **公告 → 繳費 → eTag。**

> 取代了先前「靠電梯+樓層偏好 + 現場微調」版本：偏好改為**具體車位志願序**，分發改為**統一一次算完**（不需現場逐一微調）。

**前置相依**：
- 登記要能填志願 → 看地圖選具體車位（線上或臨櫃輸入），存「戶號 → 志願序[車位編號…]」。改登記欄位/流程（04 紙本、CSV schema 見 [12-機制合規與建置規劃.md](12-機制合規與建置規劃.md) §4.6）。
- **車位分區資料（電腦選號的前置，2026-06-27）**：每個車位要標 **① 屬哪棟 A–H/S　② 靠近電梯程度　③ 可否配位（可圈選「排除區」不配）**。規劃以**地圖圈選工具**產生（物業在 B1 圖框選區域 → 指定棟別／電梯區／排除）——**一個機制同時供「電腦選號就近本棟＋靠電梯」與「排除特定區域不配」**。見 [11-選位地圖實作.md](11-選位地圖實作.md)。

### 合規檢查（對辦法 伍、二）

**符合**：登記期、臨櫃驗行照〔(八)〕、無障礙優先〔(三)〕、志願小位免抽依登記序〔(五)〕、公開抽籤監察可重現〔(九)〕、保障一位〔(五)〕、分輪〔(六)(七)〕、繳費時程〔(六)〕。

**兩個待管委會處理**：
1. ⚠️ **用語落差**：辦法 (六)(十) 對車位號碼用「**抽**」字（抽車位號碼）；本模型號碼是「**填志願 + 依順序號分發**」決定，非隨機抽號。可主張符合精神（(五) 已允許「依順序選定號碼」），但建議**管委會以決議將「選課式志願分發」明文化**（辦法 捌「未盡事宜」、玖「可修訂」）。
2. ⚠️ **候補不能省**：辦法 (六) 明文「登記戶數 > 車位數量」時須定「候補順序」。本模型「志願落選→物業補靠近棟別剩位」只在仍有剩位時成立；需求 > 總供給時**強制要候補名單** → 對應決策 B，勿漏。
