## 一句話

PDF 平面圖裡的車位編號是 **/Square 標註**，可程式抽出座標 → 與 mupdf render 的底圖對齊 → 疊上可點選的點。**最大未解問題是「分區歸類」**：抽出的純數字 1~664 是汽車／機車／自行車**混在一起**，光看數字分不出車種。

---

## 資料來源

- **檔案**：`docs/A2-5 地下一層平面圖.pdf`（= B1 地下一層）
- **頁面**：MediaBox `1684 × 2384`（直向 user space，y-up），含 `/Rotate 270` → 底圖為橫向 `2384 × 1684`。
- **車位編號**：以 PDF `/Subtype /Square` 標註存在（AutoCAD SHX 文字），每個有 `/Rect`（位置）與 `/Contents`（編號文字，UTF-16BE hex）。**注意：非真文字**，pdftotext / mupdf 結構化文字都取不到，只能解析 `/Square` 標註。
- **關鍵數字**（圖內文字檢討表）：法定汽車位 664、**法定機車位 655**、自行車 164。大車位 328（圖）/ 320（辦法）、小車位 327 — ⚠️ 圖與辦法略有出入，**以辦法為準**。

## 工具鏈（已簡化為單一腳本）

build-time Node 腳本，不進瀏覽器、不影響 SPA bundle。相依只有一個 `devDependency`：

| 套件 | 用途 |
|---|---|
| `mupdf` | render PDF → PNG 底圖（自帶 rasterizer，對 AutoCAD CAD PDF 穩；pdf.js + node canvas 對此圖會 render 成空白） |

**腳本**：`scripts/seat-demo.mjs` —— 一支搞定：
1. mupdf render B1 → `public/demo/b1.png`
2. 解析 PDF `/Square` 標註的 `/Rect`+`/Contents`（解 UTF-16BE），濾出 **928 筆純數字編號**
3. 套**座標轉換**對齊底圖
4. 產出 `public/demo/seat-select-demo.html`（底圖 + SVG 可點選車位點）

執行：`node scripts/seat-demo.mjs`（無 npm script，手動跑；改完底圖/座標重跑即可）。

> 早期曾試 pdf.js `convertToViewportPoint` + `@napi-rs/canvas` 合成檢查 + 多支探測/校正腳本（probe/extract/calibrate/build-map…），已全部移除，收斂成上面這一支。

## 座標轉換（已鎖定）

頁面 `/Rotate 270`、PDF y-up vs 影像 y-down，需把標註座標(MediaBox 1684×2384)轉到底圖顯示空間(2384×1684)。

**實測對齊版本 = transform D**（hard-code 在 `seat-demo.mjs`）：

```
x' = 2384 − y      // 顯示空間水平
y' = 1684 − x      // 顯示空間垂直
```

> 校正過程：A/B/C/D 四種 90°/鏡像對應，逐一在瀏覽器肉眼比對。B/C 黃格命中數接近但視覺上 C 上下顛倒、B 整個跑掉，**D 對齊 ~80%+**。剩餘誤差與分區歸類一起處理。

## ⚠️ 最大未解問題：分區歸類

抽出的 **928 個純數字（1~664）混了汽車／機車／自行車**，各車種編號**各自從 1 起跳會重疊**（汽車 1~664、機車 1~655）。**光看數字 `26` 無法判斷是汽車還是機車。**

可行解法（待定）：
- **按區域**：機車區 / 汽車區 / 自行車區是平面圖上不同範圍 → 用座標落在哪個 polygon 分類（先框出機車區範圍）。圖內「機車車道」「大車位」「小車位」文字可當定位錨點。
- **按車格尺寸**：機車格比汽車格小 → 用 `/Rect` 寬高過濾（目前只存中心點，需改存寬高）。
- **大／小／無障礙**：機車區內再依車格尺寸與圖上標示分；無障礙另有專屬標示。
- 最終對到 [src/data/spaces.js](../src/data/spaces.js) 的 655 筆主檔（大320/小327/無障礙8，公益位排除）。

→ 沒做完前，選位頁只能顯示「全部編號未分類」。**是接 Vue 前的關鍵卡點。**
